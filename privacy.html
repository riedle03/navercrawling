개인정보 처리방침

슬기로운 말글마이너 — 네이버 뉴스편

📰 분석 시작

슬기로운 말글마이너: 네이버 뉴스편(이하 "서비스")은 정보주체의 자유와 권리 보호를 위해 「개인정보 보호법」 등 관련 법령을 준수하며, 개인정보 처리와 관련한 절차 및 기준을 다음과 같이 공개합니다. 본 방침은 서비스 이용 과정에서 처리되는 정보와 그에 관한 이용자의 권리를 안내하기 위해 마련되었습니다.

📌 제1조(개인정보의 처리 목적)

서비스는 네이버 뉴스 검색 API를 통해 수집한 기사 데이터를 분석하여 국어 수업 및 텍스트마이닝 학습활동을 지원하는 교육용 웹서비스입니다.

서비스는 별도의 회원가입 기능을 제공하지 않으며, 이름, 연락처, 전자우편주소 등 일반적인 회원정보를 수집하여 이용자 관리에 활용하지 않습니다.

📋 제2조(처리하는 개인정보의 항목)

서비스는 원칙적으로 이용자의 개인정보를 수집하거나 저장하지 않습니다.

다만 서비스 이용 과정에서 사용자가 직접 입력하는 다음 정보가 이용자 기기 내에서 처리될 수 있습니다.

  1. 네이버 검색 API Client ID
  2. 네이버 검색 API Client Secret
  3. 바른(Bareun) API Key (선택)

위 정보는 서비스 제공자의 서버에 저장되지 않으며, 이용자의 브라우저 로컬 환경에서만 저장·사용됩니다. 서비스 제공자는 위 API 키를 별도로 수집하거나 관리하지 않습니다.

⏱ 제3조(개인정보의 처리 및 보유 기간)

서비스 제공자가 별도로 수집·보유하는 개인정보는 없습니다.

이용자가 입력한 API 키 정보는 이용자 브라우저의 로컬 저장소에 보관될 수 있으며, 이는 이용자 본인이 직접 삭제할 때까지 해당 브라우저 환경에 남아 있을 수 있습니다. 서비스 제공자는 이에 접근하거나 이를 회수하지 않습니다.

📁 제4조(개인정보파일의 등록 현황)

서비스는 이름, 연락처, 전자우편주소, 학번 등 개인정보를 체계적으로 수집·관리하는 개인정보파일을 운영하지 않습니다.

🤝 제5조(개인정보의 제3자 제공)

서비스 제공자는 이용자의 개인정보를 제3자에게 제공하지 않습니다.

다만 이용자가 직접 입력한 API 키를 사용하여 네이버 검색 API 및 바른 API와 통신할 수 있으며, 이 과정은 이용자의 요청에 따라 Vercel 서버리스 프록시를 경유하거나 이용자 브라우저 환경에서 이루어집니다. 프록시는 API 키를 저장하지 않으며 단순 중계 역할만 수행합니다. 서비스 제공자가 이용자의 개인정보를 제3자에게 이전하는 구조는 아닙니다.

🏢 제6조(개인정보 처리의 위탁)

서비스 제공자는 이용자의 개인정보 처리 업무를 외부에 위탁하지 않습니다.

⚖️ 제7조(정보주체와 법정대리인의 권리·의무 및 행사방법)

정보주체는 언제든지 자신의 개인정보 보호와 관련하여 권리를 행사할 수 있습니다. 다만 본 서비스는 서비스 제공자가 별도로 개인정보를 수집·보유하지 않으므로, 일반적인 회원정보 열람·정정·삭제 요청의 대상이 되는 정보가 없습니다.

이용자는 다음과 같은 방법으로 직접 정보를 관리할 수 있습니다.

  1. 브라우저에 저장된 API 키 삭제 (설정 모달에서 직접 삭제 가능)
  2. 브라우저 저장 데이터 초기화
  3. 다른 브라우저 또는 시크릿 모드 사용

만 14세 미만 아동의 경우에도 본 서비스는 별도의 개인정보 수집 구조를 두고 있지 않습니다. 다만 아동이 외부 API 키를 직접 발급·입력하여 사용하는 경우에는 보호자 또는 교사의 안내 아래 이용하는 것을 권장합니다.

🗑️ 제8조(개인정보의 파기)

서비스 제공자가 별도로 수집·보유하는 개인정보는 없으므로, 서비스 제공자 차원의 파기 대상 개인정보는 없습니다.

이용자 브라우저에 저장된 API 키 정보는 이용자가 직접 삭제할 수 있으며, 브라우저의 캐시·저장소 삭제 기능을 이용하면 제거할 수 있습니다.

🛡️ 제9조(개인정보의 안전성 확보조치)

서비스는 개인정보를 서버에 저장하지 않는 구조를 기본으로 하며, 사용자가 입력한 API 키는 브라우저 로컬 환경에서만 저장·사용되도록 설계되어 있습니다. 서비스 제공자는 개인정보 보호를 위해 다음과 같은 원칙을 적용합니다.

  1. 회원가입 및 개인정보 직접 수집 기능 미제공
  2. 이름, 연락처, 전자우편주소 등 개인정보 미보관
  3. 사용자가 입력한 API 키의 서버 비저장 원칙
  4. 공개 페이지를 통한 방침 고지 및 문의처 안내

다만 브라우저 로컬 저장소는 이용자 기기 환경에 따라 접근될 수 있으므로, 공용 기기에서는 사용 후 저장 정보를 삭제하는 것을 권장합니다.

📬 제10조(개인정보 보호책임자 및 문의처)

서비스의 개인정보 보호 관련 문의는 아래 연락처로 하실 수 있습니다.

🏛️ 제11조(권익침해 구제방법)

정보주체는 개인정보 침해에 대한 구제를 받기 위하여 개인정보분쟁조정위원회, 개인정보침해신고센터 등 관련 기관에 상담 또는 신고를 할 수 있습니다.

📅 제12조(개인정보 처리방침의 변경)

본 개인정보 처리방침은 2026년 3월 15일부터 적용됩니다.
법령, 서비스 기능 또는 운영 방식의 변경이 있는 경우에는 본 페이지를 통하여 변경 사항을 안내합니다.
